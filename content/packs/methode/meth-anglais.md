Les documentations, les messages d'erreur, les offres d'emploi, les conférences, les réunions dans beaucoup d'entreprises : l'informatique parle anglais. Pas besoin d'être bilingue, mais il faut **lire l'anglais technique** sans effort et comprendre les termes du métier.

## Le niveau qu'il faut

- **Indispensable** : lire une documentation et un message d'erreur. C'est un anglais très répétitif, qui s'apprend vite.
- **Très utile** : comprendre une vidéo technique, écrire un message clair (ticket, commentaire de code, *pull request*).
- **Un plus** : participer à une réunion en anglais, utile dans les grandes entreprises et les équipes internationales.

## Le vocabulaire qui revient tout le temps

| Anglais | Français | Contexte |
|---|---|---|
| deploy / deployment | déployer / déploiement | mettre en production |
| release | version publiée | « la release 2.3 » |
| bug / fix | anomalie / correctif | « fixer un bug » |
| issue / ticket | demande, problème | suivi des tâches |
| pull request (PR) / merge request | demande de fusion | revue de code |
| pipeline | chaîne de traitement | data ou CI/CD |
| throughput / latency | débit / latence | performance |
| deprecated | obsolète, à ne plus utiliser | documentation |
| out of memory | mémoire insuffisante | erreur |
| timeout | délai dépassé | réseau, requêtes |
| rollback | retour arrière | déploiement raté |
| on-call | astreinte | exploitation |

Le lexique de l'application donne l'équivalent anglais de chaque terme : servez-vous-en.

## Progresser sans y passer ses soirées

:::astuce
- **Lisez la documentation en anglais** dès que possible, avec un outil de traduction à portée de main pour les phrases difficiles.
- **Réglez votre téléphone ou vos outils en anglais** : vous apprendrez le vocabulaire informatique sans effort.
- **Regardez des conférences techniques** avec sous-titres anglais (chaînes des fondations Apache, CNCF, des fournisseurs cloud).
- **Écrivez vos messages de commit en anglais** : c'est la norme dans beaucoup d'équipes.
:::

:::metier En entreprise
Les certifications AWS existent en français, mais beaucoup d'autres (Linux Foundation, HashiCorp, Databricks…) seulement en anglais. Un anglais technique de lecture correct est donc aussi nécessaire pour vos certifications.
:::

## À retenir

- Lire l'anglais technique est indispensable ; le parler est un plus.
- Le vocabulaire est répétitif : deploy, release, fix, pull request, pipeline, timeout, rollback…
- Outils et documentation en anglais au quotidien, commits en anglais.
- Plusieurs certifications ne sont disponibles qu'en anglais.
