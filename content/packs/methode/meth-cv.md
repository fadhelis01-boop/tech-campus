Vous avez les compétences ; il faut maintenant qu'un recruteur les **voie**. Pour un profil en reconversion, trois vitrines comptent : le CV, le profil LinkedIn et le profil GitHub.

## Le CV technique

:::methode Structure efficace (une page, deux au maximum)
1. **Titre clair** : « Data engineer junior » ou « Ingénieur cloud / DevOps junior » — le métier visé, pas « en reconversion ».
2. **Accroche** de 3 lignes : votre valeur (compétences techniques + expérience métier précédente).
3. **Compétences techniques** groupées : Langages (Python, SQL, Bash) · Cloud (AWS) · Outils (Git, Docker, Terraform, Airflow).
4. **Certifications** : avec le lien de vérification. L'onglet Certifications génère ce bloc pour vous.
5. **Projets** : 3 projets, chacun avec le problème, les technologies, le résultat, et le lien GitHub.
6. **Expérience** : votre parcours précédent, en mettant en avant ce qui est transférable (analyse, rigueur, gestion de projet, connaissance d'un secteur).
7. **Formation.**
:::

:::astuce Les mots-clés
Beaucoup d'entreprises filtrent les CV automatiquement (ATS, *applicant tracking systems*). Reprenez les **termes exacts** de l'offre (« Airflow », « dbt », « Terraform », « Kubernetes ») s'ils correspondent à vos compétences réelles. N'inventez jamais : tout ce qui est sur le CV peut être demandé en entretien.
:::

## LinkedIn

- **Titre** : le métier visé + vos technologies principales.
- **Section « Licences et certifications »** : ajoutez chaque certification avec son badge (Credly).
- **Publiez** de temps en temps : un projet terminé, une certification obtenue, ce que vous avez appris. Les recruteurs tech utilisent massivement LinkedIn.

## GitHub, votre portfolio

- Un **profil propre** : photo ou avatar, courte bio, README de profil.
- **Épinglez** vos 3 à 6 meilleurs projets.
- Des **commits réguliers** montrent votre constance (le calendrier vert).
- Chaque projet a un **README** soigné (voir la leçon sur les projets).

## Trouver ses premières opportunités

- **L'alternance** est une voie royale en reconversion : vous êtes formé et payé, et l'entreprise vous embauche souvent ensuite.
- **Les ESN** (entreprises de services du numérique) recrutent beaucoup de juniors et offrent une grande variété de missions.
- **Les événements** : meetups, conférences locales, communautés (data, cloud, Python) — on y rencontre des recruteurs et des mentors.
- **France Travail** et l'**Apec** publient des offres et peuvent accompagner les projets de reconversion.

## À retenir

- CV : métier visé, compétences groupées, certifications vérifiables, 3 projets, expérience transférable.
- Mots-clés de l'offre, sans jamais rien inventer.
- LinkedIn : titre, certifications, publications ; GitHub : projets épinglés et README.
- Alternance, ESN, événements : les portes d'entrée des juniors.
